# 모둠 카드 게임

교실에서 여러 모둠이 동시에 진행할 수 있는 카드 게임 웹앱입니다.

- 한 게임(방)에 2~6명 참여, 카드 더미(각 카드 1장씩)를 공유
- 각자 화면에 자신이 뽑은 카드가 색깔별로 나열됨
- 인원수만큼 순서가 정해지고, 자기 차례에만 "카드 뽑기" 버튼이 보임
- 교사는 한 화면에서 최대 20개 모둠 방을 만들고 QR코드로 배포
- 학생/학급 규모가 커지면 Firebase 프로젝트를 여러 개(그룹 A/B/C)로 나눠 무료 한도 안에서 확장 가능

React(Vite) + Firebase Realtime Database로 만들어졌습니다. 서버를 직접 운영하지 않아도
Firebase 무료 티어로 충분히 감당할 수 있습니다.

## 0. 규모별 안내 (중요)

Firebase 무료(Spark) 요금제는 **Realtime Database 동시 연결이 프로젝트당 100개로 고정**돼
있습니다 (유료로 늘릴 수 없는 기술적 한도). 학생 한 명 + 교사 한 명이 각각 접속 1개를 씁니다.

- **한 학급(약 20~30명) 정도만 쓸 경우**: Firebase 프로젝트 1개로 충분합니다. 아래 "1. Firebase
  프로젝트 준비"만 한 번 하면 됩니다.
- **학년 전체/여러 반이 동시에 쓸 경우** (예: 10개 반 x 24명 = 240명): 프로젝트 1개로는 100개
  한도를 넘기므로, Firebase 프로젝트를 2~3개(그룹 A/B/C) 만들어서 반별로 나눠 접속하게 해야
  합니다. 앱은 교사가 대시보드에 처음 들어갈 때 그룹을 고르는 화면을 보여주고, 학생 수를
  입력하면 여유 있는 그룹을 추천해줍니다. 그룹별 현재/최대 인원도 실시간으로 표시됩니다.
  이 경우 "1. Firebase 프로젝트 준비"를 그룹 수만큼(최대 3번) 반복하면 됩니다.

## 1. Firebase 프로젝트 준비 (그룹마다 반복)

1. https://console.firebase.google.com 에서 새 프로젝트를 만듭니다.
2. 왼쪽 메뉴 **Build > Realtime Database**에서 데이터베이스를 생성합니다. (위치는 asia-southeast1 등 가까운 리전 권장)
3. **규칙(Rules)** 탭에서 아래처럼 설정합니다. (수업용 임시 공개 규칙 — 외부에 URL이 알려지지 않는 한 안전하지만, 장기 운영 시에는 더 제한적인 규칙을 권장합니다)
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
4. 프로젝트 설정(⚙️ > 프로젝트 설정) > **일반** 탭 하단에서 "웹 앱 추가"를 눌러 웹 앱을 등록하고, 표시되는 설정값(apiKey, authDomain 등)을 복사해둡니다.
5. 그룹이 하나만 필요하면 여기서 끝. 여러 그룹이 필요하면 위 1~4번을 반복해서 그룹 B, C용
   Firebase 프로젝트를 추가로 만듭니다.

## 2. 로컬 개발 환경 설정

```bash
npm install
cp .env.example .env
```

`.env` 파일을 열어 Firebase 콘솔에서 복사한 값을 채웁니다. 그룹 A만 쓴다면 `VITE_FIREBASE_A_*`
7개만 채우면 되고, 나머지 `_B_`, `_C_` 항목은 비워둬도 됩니다 (그룹 선택 화면에 설정된
그룹만 표시됩니다).

```bash
npm run dev
```

## 3. 카드 이미지 넣기

`src/data/cards.js` 에 카드 목록(색상, 이름)이 정의되어 있습니다. 실제 카드 이미지가 준비되면:

1. 이미지 파일을 `public/cards/` 폴더에 넣습니다.
2. `src/data/cards.js`에서 해당 카드의 `image` 값을 파일명으로 바꿉니다. (예: `image: 'red-1.png'`)

카드 개수/색상 그룹은 자유롭게 추가·수정할 수 있습니다. 단, 방을 만들 때 이 목록 그대로
셔플되어 카드 더미가 되므로, 실제 물리 카드 세트와 구성을 맞춰주세요.

## 4. 사용 방법

0. (Firebase 그룹을 2개 이상 설정한 경우) 교사가 대시보드에 처음 들어가면 그룹 선택 화면이
   뜹니다. 오늘 이 반의 학생 수를 입력하면 여유 있는 그룹이 "추천" 표시로 안내되고, 그룹별
   현재/최대 인원(예: 48/90)도 실시간으로 보입니다. 한 번 고르면 다음 접속부터는 기억하고,
   상단의 "그룹 변경"으로 언제든 바꿀 수 있습니다.
1. `/` (교사 대시보드)에서 "새 모둠 방 만들기"를 눌러 모둠 수만큼 방을 생성합니다. (최대 20개)
   기본 이름은 "1모둠", "2모둠"... 순서대로 붙지만, 방 카드의 ✏️ 버튼으로 언제든 원하는
   이름으로 바꿀 수 있습니다.
2. 각 방 카드에 표시된 QR코드를 해당 모둠에게 보여주면, 학생들은 스캔 후 이름을 입력해 입장합니다.
3. 모둠 인원(2~6명)이 다 들어오면 교사가 "게임 시작"을 누릅니다.
4. 학생 화면에는 자기 차례에만 "카드 뽑기" 버튼이 나타나고, 누른 카드는 색깔별로 화면에 쌓입니다.
   "이 카드는 내 OO에 닿아야 해요" 같은 터치 카드가 나오면, 화면 속 카드는 그림일 뿐이라
   실제로 몸에 붙일 수는 없습니다. **포스트잇이나 이면지 조각 등 버려질 종이를 그 자리에서
   대신 붙이는 걸 추천**합니다 (준비물 없이, 쓰레기가 될 종이를 한 번 더 재사용하는 방식).
5. 지시사항(몸짓/말)을 수행하지 못하는 학생이 나오면, 같은 방의 아무 학생이나 그 이름 옆
   "딱 걸렸어!" 버튼을 눌러 지목합니다. 누르는 순간 그 방 모든 화면에 커졌다 작아지는 사이렌
   알림이 뜹니다 (이 시점에는 아직 누구도 아웃되지 않습니다). 잠시 후 지목당한 학생의 화면에만
   "정말 아웃을 인정하시겠어요?" 확인창이 뜨고, 본인이 인정해야만 실제로 아웃 처리됩니다.
   다른 학생이 장난으로 눌러도 본인이 인정하지 않으면 그대로 게임을 계속할 수 있습니다.
   한 명만 남으면 자동으로 게임이 종료되고 우승자가 표시됩니다.
6. 다시 하려면 교사 대시보드에서 "초기화"를 누르면 같은 방 코드로 새 덱이 섞여 재시작됩니다.

## 5. 배포 (Vercel 예시)

1. GitHub에 이 저장소를 push 합니다.
2. https://vercel.com 에서 저장소를 import 합니다.
3. 프로젝트 설정 > Environment Variables에 `.env`에 넣었던 `VITE_FIREBASE_A_*` (및 사용한다면
   `_B_`, `_C_`) 값들을 동일하게 등록합니다.
4. Deploy를 누르면 배포된 URL이 교사/학생 모두가 접속할 주소가 됩니다.
